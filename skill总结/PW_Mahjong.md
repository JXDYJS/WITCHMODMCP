**Author:** 逍遥梦尘

**Tags:** Mahjong-themed, 8 packs, 241 cards, 1 partner  
**Mod Type:** Lua + C# hybrid (DLL for core scan/check logic)

---

## Mod Overview

A mahjong-themed mod that turns the game's buff system into mahjong tiles. Players stack 34 different tile buffs (Man/Tong/Tiao + Winds + Dragons) to form winning hands (Thirteen Orphans, Seven Pairs, Standard Win).

### Key Features

- **241 Cards across 8 Packs:**
  - P1 (雀士, 34): Basic mahjong tiles
  - P2 (雀杰, 2): Deal cards
  - P3 (雀圣, 17): Cheat/trick cards (5 schools: ESP, Sleight of Hand, Mahjong Expertise, Mind Games, Tech Gadgets)
  - P4-P8 (雀魔/雀神/雀鬼/雀皇/雀豪, 170+): Cross-pack synergy with existing mods
- **34 Tile Buffs:** Each mahjong tile is a stackable buff
- **Win Detection:** C# scan logic checks 13 Orphans, 7 Pairs, Standard Win
- **1 Partner:** Wealthy Sweetheart (富婆小甜心) — +2 Gold/+2 HP per turn per Mahjong Majo stack
- **1 Relic:** Wealthy Sweetheart relic
- **Rarity System:** Basic (34), Rare-2 (winds), Rare-3 (dragons) for magic mahjong
- **Cross-mod Linking:** Packs P4-P8 link to specific other mods

## Data Config Format

### Card CSV (`card_mahjong.csv`) — Generated by `gen_all.py`

Standard 12-column format:
```
Id,Rarity,Expend,Tag,PackBelong,InitScript,DrawScript,UseScript,DropScript,Icon,Effects,Action
```

Card generation pattern (from `gen_all.py`):
```python
def use_script(buff_id, extra):
    base = 'self:SetStatus("Self"); self:AddBuff("PW_Mahjong_buff_mahjong_{}", "1"); self:AddBuff("PW_Mahjong_buff_mahjong_majo", "1"); self:DrawCount("1"); {}'.format(buff_id, extra)
    return q(base)
```

Every basic tile card:
1. Adds its tile buff (e.g., `PW_Mahjong_buff_mahjong_1wan`)
2. Adds "majo" buff (win condition counter)
3. Draws 1 card
4. Triggers additional effects

### Buff CSV
Custom mahjong tile buffs — no special apply/clear scripts (pure stacking counters).

### Card Packs
8 card packs defined:
- `cardpack_amateur1`, `cardpack_amateur2` (basic tiles)
- `cardpack_professional1` through `cardpack_professional6` (magic tiles)

## Key Patterns & Techniques

1. **C#-Driven Win Detection:** `CS.MJ.CardScripts.ScanAndCheck(self)` returns:
   - `-1` → reorder buffs (no action yet)
   - `0` → false win: -5 gold + clear all mahjong buffs
   - `1` → 13 Orphans (十三幺): +2000 gold, give win
   - `2` → 7 Pairs (七对子): +500 gold, give win
   - `3` → Standard Win (标准胡): +100 gold, give win

2. **Buff-Based Mahjong System:**
   - 34 tile buffs + 1 "majo" buff (win condition tracker)
   - Buff levels track tile count (1-4 copies)
   - `reorderMahjongBuffs()` maintains consistent buff order for visual display

3. **Lua ↔ C# Interop:**
   - Lua calls `CS.MJ.CardScripts.ScanAndCheck(self)` for win check
   - Lua calls other `CS.MJ.CardScripts.*` for trick card mechanics
   - C# methods called with `self` as `ScriptExecutor` parameter

4. **Python CSV Generation:**
   - `gen_all.py` generates card CSV programmatically with loop patterns
   - `gen_text.py` generates multilingual text CSV
   - Both auto-deploy to game directory

5. **Pack Structure:** 8 packs with increasing complexity:
   - P1: Simple tiles (add buff, draw 1)
   - P3: Trick cards with check dice, burn mechanics, spell generation
   - P4-P8: Cross-mod linking (e.g., "法术序列", "混沌乐团", "血鬼谱系")
   - Tags distinguish schools: `PW_Mahjong_keyword_MagicMahjong`, `PW_Mahjong_keyword_Qianshu`

6. **Partner Economy Loop:** Wealthy Sweetheart gives gold per majo stack per turn — creates a scaling economy engine

## Asset Pipeline (Python Tools)

### `gen_all.py` — Card CSV Generator
- Template-based card generation using Python string formatting
- Supports multiple language packs (magic/sheng) via loop patterns
- Auto-deploys to game directory via `shutil.copy2`
- CSV integration: reads existing file, inserts new lines, preserves header

### `gen_text.py` — Text CSV Generator
- Generates 4-language text entries (CN, EN, ZH-Hant, JA)
- Preserves existing text entries, only appends new content
- Filters/sorts entries by type

## Extractable Lessons

1. **C# DLL for performance-critical logic** (win detection scanning all buffs is expensive in Lua)
2. **CSV generation via Python** enables large content mods (241 cards) without manual editing
3. **Buff-as-resource pattern** — using buff levels to track player resources enables complex system interactions
4. **Cross-mod linking** by referencing other mods' card/buff IDs in card scripts
5. **Minimal Lua entry** — PW_Mahjong's `ModConfig:Setup()` is empty; all logic is in CSV + DLL
6. **Multi-variant cards** — 34 tiles × 5 magic variants = 170 cards with systematic naming
7. **Clear victory/gold economy** — win conditions directly reward gold, creating alternative win condition
8. **Tag-based card filtering** — `MJ_IsMagicMahjongCard()` checks ID pattern or tag for flexibility
